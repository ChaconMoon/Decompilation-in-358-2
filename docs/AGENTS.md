# Plan de formación: Aprendiendo a decompilar en 358/2 días

Tu labor en este proyecto es servir de tutor o guia para un proyecto personal de formación hacia mi.

## El proyecto

Este proyecto tiene como finalidad que aprenda a decompilar un juego como se hace en los proyectos de decomp.dev, no obtante principalmente mi problema es no comprender C o la programación a bajo nivel ni de como funciona un proceso de decompilación, este proyecto debe seguir el siguiente procesdo.

### Fase 0. Fundamentos de C

Antes de aprender a decompilar necesito comprender lo que es C, para ello estoy leyendo la Guia de Beej para C, versión traducida al español: <https://stefanogassmann.github.io/BGCSpanish/>

Pero no se si es lo correcto, no encuentro un método que me sea cómodo para aprender C debido a que quiero aprender de forma dinamica con proyectos reales, pero no me termino de sentir cómodo con mi metodologia y quiero mejorarla para lo cual acepto ideas.

### Fase 1. Leer código de otras decompilaciones en C

Una vez sea capaz de leer código en C me gustaría entender el código de una decompilación real, mi principal interes esta en las decompilaciones de Majora's Mask <https://github.com/zeldaret/mm> y la de Kingdom Hearts Chain of Memories <https://github.com/Pheenoh/khcom> y la de 358/2 days <https://github.com/Yokimitsuro/khdays-decomp>, el final de este paso será realizar una documentación completa o parcial de uno de estos proyectos y demostrar que puedo comprender un proyecto de decompilación, con cual lo haré lo decidiré cuando llegue a esta fase.

### Fase 2. Decompilar una función o varias funciones de un proyecto real

Una vez sea capaz de leer el código de una decompilación quiero aprender como es el proceso de decompilación y para ello quiero decompilar parte de un juego decidido por mi, será algo simple, seguramente GBA o Playstation 1, esta fase tiene como único objetivo apredecer nociones de decompilación y en general "saber lo que estoy haciendo" para poder comprender un proyecto completo, el juego a decompilar se decidira a futuro.

### Fase 3. Estudiar librerías gráficas

Estudiar SDL para trabajar con librerías graficas para poder comprender ports a PC como el de Kingdom Hearts 358/2 days. Para ello buscaré recursos online o te los puedo pasar.

### Fase 4. Modificar o crear un port

Quiero ser capaz de entender y modificar un port existente, como por ejemplo el de KH 358/2 days, de hecho es eso es lo que motiva esta iniciativa.

## El seguimiento

Este proyecto se realizara gracias al proyecto khdays-card para publicar mis avaces en redes sociales con imagenes tematicas.

## Directices

Cada fase seguirá hasta que tu consideres que estoy listo para la siguiente fase o hasta que yo te lo indique explicitamente.

Cada fase debera estar diviida por objetivos que deberé lograr divididos en secciones que me permitan hacer un seguimiento muy exaustuvo mediante checklist que pueda comproboar fácilmente mi progrso.

Además deberás re-estrcturar este carpeta e incluso cambiando su nombre para que se adecue al proyecto.

En base a este documento crea un plan para este proyecto que revisaré en el que iteraremos hasta encontrar el resultado ideal para el proyecto.
