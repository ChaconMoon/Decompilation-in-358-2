# Hub de Contenido Social y Difusión (#DecompilandoEn358Dias)

Este directorio centraliza las adaptaciones del diario técnico de aprendizaje (`docs/diario/`) a formatos de difusión y redes sociales profesionales.

---

## Estructura de Directorios

```text
docs/social/
├── README.md               # Esta guía
└── linkedin/               # Publicaciones adaptadas para LinkedIn
    └── post-dia-23.md      # Día 23: Estructurando el proyecto (Hito del 0.01% y arquitectura)
```

---

## Flujo de Trabajo para Redes

1. **Fuente de la Verdad**: La entrada completa del diario en `docs/diario/dia-XX.md`.
2. **Tarjeta Visual**: Exportar la tarjeta correspondiente en `docs/diario/diario-images/dia-XX.png` desde `tools/khdays-card/`.
3. **Adaptación**: Destilar los hitos técnicos, reflexiones de aprendizaje y dilemas éticos en un post con gancho, formato ágil y llamada a la acción.
4. **Publicación**: Copiar el texto a LinkedIn acompañado de la tarjeta gráfica y enlace a GitHub.
